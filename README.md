# Avera — Industrial Marketplace (prototype landing page)

Avera connects industrial buyers in Mexico with companies that already have the parts they need in stock, new or used. This repository holds the prototype landing page: a hero section with a search demo, the problem statement, the value proposition, how it works, why Avera, and the waitlist call to action.

## Technology

- One self-contained static `index.html`. HTML, CSS, vanilla JavaScript, and the images and videos are all inlined.
- Google Fonts (Inter, Inter Tight).
- Hosted on Netlify. `netlify.toml` publishes the repository root, and there is no build step.

## Run locally

Open `index.html` in a browser, or run `netlify dev --port 8889`.

## Intended address

`https://avera-marketplace.netlify.app`. To set it, rename the Netlify project under Project configuration → General → Project details → Change project name.
